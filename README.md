# Mario Cabrero Portfolio

Static portfolio for [cartagogit.github.io](https://cartagogit.github.io/). It is intentionally dependency-free so GitHub Pages can publish it directly from the `main` branch.

## Local preview

```console
bunx --bun serve . -l 4173
```

Open `http://localhost:4173`. The public messaging describes verified engineering capabilities without naming or exposing employer projects.
